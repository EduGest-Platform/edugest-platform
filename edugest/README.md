# EduGest Platform

**EduGest** es un proyecto académico orientado a la gestión educativa.

> El stack tecnológico (backend, base de datos y frontend) está pendiente de decisión por el equipo. Este repositorio mantiene una estructura neutral hasta que se acuerde la arquitectura.

## Objetivo

Construir una plataforma de gestión educativa de forma colaborativa, organizada y verificable.

## Organización

- `docs/`: documentación del proyecto y decisiones técnicas.
- `src/`: código fuente (estructura por definir).
- `tests/`: pruebas automatizadas.
- `.github/`: plantillas y automatización de GitHub.
